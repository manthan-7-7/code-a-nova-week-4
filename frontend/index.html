Temporal Integrity & Leakage Prevention Architecture

ShieldML strictly enforces zero future-data leakage across all data processing and evaluation stages:

  • Chronological Splits: Training (70%), Validation (15%), and Testing (15%) are separated by non-overlapping temporal cutoffs.
  • Strict Past-Looking Velocity: 1h, 24h, and 7d rolling counts are computed backwards in time for each user.
  • Training-Only Statistics: Merchant mean/std amount baselines and device frequencies are fitted strictly on the training partition.
  • Untampered Test Evaluation: SMOTE/ADASYN resampling is restricted to training data only. Test set retains raw class distribution.
